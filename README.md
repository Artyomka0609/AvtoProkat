## Описание

«АвтоПрокат» помогает посетителю подобрать автомобиль для городской поездки, путешествия или деловой встречи. На сайте доступны каталог, тарифы на разные сроки, калькулятор стоимости, условия аренды и контакты с картой.

Интерфейс адаптирован для компьютеров, планшетов и телефонов. Общие шапка, навигация и подвал используются на всех страницах. В подвале размещена фраза **«все данные защищены»**.

## Контрольная работа №2

Тема: разработка адаптивного сайта с использованием CSS-фреймворка **Bootstrap 5**.

Bootstrap используется для адаптивной сетки, карточек, форм, таблицы тарифов и аккордеона FAQ. React управляет интерактивными элементами, React Router — переходами, Vite — локальным сервером и сборкой. Собственные CSS-стили задают индивидуальное оформление сервиса.

## Как запустить локально

Нужен **Node.js 22.12+ или 24+**.

### Windows: двойным щелчком

1. Скачать репозиторий через **Code → Download ZIP** и распаковать.
2. Открыть `START.cmd`.
3. При первом запуске дождаться установки зависимостей. Сайт откроется в браузере автоматически.
4. Оставить окно сервера открытым на время работы. Для остановки нажать **Ctrl + C**.

Повторный запуск `START.cmd` открывает уже работающий сайт. Если основной порт занят другим приложением, выбирается свободный порт.

### Через терминал VS Code

```bash
git clone https://github.com/Artyomka0609/AvtoProkat.git
cd AvtoProkat
npm ci
npm run dev
```

Открыть адрес, который напечатает Vite, обычно **http://127.0.0.1:58327/**.

Исходный `index.html` не предназначен для запуска двойным щелчком: React-приложению нужен сервер разработки или готовая сборка на хостинге.

## Реализованные элементы интерфейса

1. Слайдер с переключением фотографии, названия и стоимости автомобиля.
2. Каталог из пяти моделей в трёх классах.
3. Совместная фильтрация по классу и коробке передач; сортировка по стоимости.
4. Количество найденных автомобилей, сообщение о пустом результате и сброс фильтров.
5. Диалог характеристик с ценой и залогом; закрытие кнопкой и клавишей Escape.
6. Переход к форме с автоматически выбранным автомобилем.
7. Календарные поля и проверка обязательных данных, имени, телефона и периода аренды.
8. Расчёт стоимости с учётом длительности; залог показывается отдельно.
9. Раскрывающийся FAQ на Bootstrap.
10. Встроенная карта Яндекса и выбор маршрута на автомобиле, общественном транспорте или пешком.
11. Ссылки `tel:` и `mailto:`, внешние социальные ссылки.
12. Мобильное меню, видимый фокус с клавиатуры, кнопка «Наверх» и поддержка уменьшения анимации.

## Правила расчёта стоимости

- 1–6 суток: базовая стоимость за сутки.
- 7–29 суток: скидка **10%** на весь период.
- От 30 суток: скидка **20%** на весь период.
- Неделя — 7 суток, месяц в тарифной таблице — 30 суток.
- Минимальная аренда — сутки; максимальный период формы и калькулятора — 365 дней.
- Возвратный залог не включается в стоимость аренды.

Пример для Toyota Camry: **4 500 ₽** за сутки, **28 350 ₽** за 7 суток и **108 000 ₽** за 30 суток.

## Как проверить работу

1. Открыть страницы и проверить переходы, активный пункт меню и подвал.
2. Переключить автомобили в слайдере.
3. В каталоге выбрать класс и коробку, проверить сортировку и пустой результат.
4. Открыть характеристики, затем нажать «Забронировать»: автомобиль должен подставиться в форму.
5. Отправить пустую форму, затем указать неверный телефон, дату в прошлом или окончание раньше начала.
6. Заполнить корректные данные: должно появиться подтверждение с автомобилем, датами, стоимостью и залогом.
7. В калькуляторе проверить 1, 7 и 30 дней, затем ввести 0 или дробное число.
8. Раскрыть FAQ. Открыть контакты, выбрать способ передвижения и построить маршрут.
9. Уменьшить ширину окна: проверить карточки, меню, форму и таблицу тарифов.
10. Выполнить `npm test` и `npm run build`.

Автоматические проверки покрывают границы скидок, календарные дни, високосный год, корректную заявку, обязательные поля и неверные периоды аренды.

## Работа с данными

Форма работает в демонстрационном режиме: значения проверяются в браузере и не отправляются на сервер. Имя и телефон не сохраняются в `localStorage` или cookies. Фактическое бронирование не создаётся, оплата не принимается.

Контакты, адрес, тарифы и условия приведены как примеры. Фотографии иллюстрируют модели автомобилей и офис. Социальные ссылки открывают главные страницы платформ. Перед использованием реальной компанией нужно заменить данные в `src/data.js` и подключить серверную обработку заявок.
